3. estimate 단계 실패했으면: brew install libomp && /Users/ohyeahdani_m1/workspace/venv_common/bin/pip install lightgbm pandas scikit-learn 후 estimate.py train && evaluate && predict 재실행
4. finalize-sold 결과 확인: [done] finalized N 건수 — N>0이면 웹 /sold 페이지와 지도 파란 마커에 낙찰 매물이 보여야 함
5. evaluate 출력의 가율 MAE가 베이스라인(지역 평균)보다 낮은지 확인
6. cd crawler && ./install_cron.sh && ./install_cron.sh show — 주간 학습 크론 포함 재등록

주의사항

- uuid .in_() PostgREST 쿼리는 150개 초과 시 NAS nginx 414 — 항상 150 chunk
- usage_nm(법원 분류)은 오표기 있음 — 매물 성격 판정은 conv_addr의 [집합건물/[건물/[토지 마커가 진실. 파생 분류 가드는 반드시 derived_category.py의 location_excluded()에만 추가하고, 룰 변경 후 backfill-categories --force
- data.go.kr 일일 쿼터: molit deals는 MOLIT_DAILY_BUDGET(기본 900콜)로 제한됨
